# 몰락 다큐 채널 프로필 (기본값)

사용자가 요청에서 직접 말한 값이 있으면 그 값이 항상 우선한다. 없을 때만 여기 기본값을 쓴다.

## 채널 성격
- 장르: 기업·브랜드·인물·산업의 **몰락 다큐멘터리**
- 한 줄 정의: "한때 저렇게 잘나가던 존재가 도대체 왜 이렇게 됐을까?"에 답하는 스토리형 다큐
- 비율 목표: **정보 전달 40% + 스토리 40% + 미스터리 20%**

## 기본 입력값
- 목표 영상 길이: **20~25분** (기본 20분). 프로젝트에서 사용자가 별도 지시하면 그것이 우선
  - 근거: 동일 장르 레퍼런스 9편 중 조회수 상위 2편(117만·29만)이 20~22분으로 가장 짧았다. 27분대 3편은 전부 중하위권. 길이를 늘려 얻는 것이 없다
  - 25분을 넘기지 않는다. 분량이 넘치면 섹션을 늘리지 말고 곁가지 에피소드를 버린다
- 주 시청자: **30~70대 한국인**, 경제·기업 관심층 + 일반 대중
- 영상 톤: **차분한 다큐** (선택지: 차분한 다큐 / 긴장감 있는 스토리 / 경제 해설 / 미스터리형)

## 시청자 폭이 넓다는 것의 의미
몰락은 향수를 자극하는 소재다. 40~70대는 그 브랜드의 전성기를 **직접 겪은** 세대이고, 30~40대는 이야기로만 아는 세대다. 둘 다 잡으려면:
- **소재**: 한국인이 실제로 써봤거나 이름은 아는 브랜드에 가산점. 완전한 해외 B2B 기업은 후순위
- **자료화면**: 한국 방영 광고·국내 뉴스 화면을 우선 확보한다. 그 세대의 기억을 직접 건드린다

집필 단계에서 실제로 문장에 적용할 규칙(용어 풀어쓰기 · 연도 앵커 · 체감 단위 환산 · 톤 유지)은 `prompts/collapse-style.md` 1절에 있다.

## 분량 환산
- 분당 글자수: **474자** (공백 포함, 완성 영상 2편 실측 평균)
  - 노키아 편 — 대본 9,365자 ÷ 19분 24초 = **482.6자/분** (2026-09-18, CapCut 자막 트랙 실측)
  - 홈플러스 편 — 대본 10,376자 ÷ 22분 20초 = **464.6자/분** (2026-09-19, CapCut 자막 트랙 실측)
  - 두 편 평균 473.6 → **474자**. 편차가 18자(3.8%) 있어 평균을 쓴다
  - 이전 값 430자는 추정치였다. 그 값으로 잡으면 목표보다 **10% 넘게 짧은 영상**이 나온다
  - 편이 쌓이면 다시 평균을 낸다. 계산식: 완성 영상의 01_대본.txt 글자수 ÷ 실제 분수
- 목표 글자수 = 분 × 474자. 허용 범위 ±8%
  - **20분 ≈ 9,480자(기본)** / 22분 ≈ 10,430자 / 25분 ≈ 11,850자

## 말투

**채널의 소리 한 줄: 길게 깔고, 짧게 꽂는다.** 자료를 차분히 보여주다가 중요한 순간에 짧고 쉬운 말로 꽂는다. 기준 문장 여섯 개와 배치 규칙은 `prompts/collapse-style.md` 1절에 있다.

> 근데 이상한 게 하나 있어요. / 그럴 만도 했습니다. / 그런데 접었어요. /
> 사람들이 무서워서 말을 못 했던 겁니다. / 팔 물건이 없는 9개월이었습니다. /
> 없는 게 별로 없었습니다. 그런데 딱 하나를 놓쳤죠.

- 기본: **합쇼체(~습니다 / ~입니다)** — 차분하게 사실을 짚어주는 다큐 내레이션 톤
- 목표 비율: **합쇼체 60% : 해요체 40%** (문장 끝 기준, 각 ±10%p)
- 해요체(~어요 / ~예요 / ~죠 / ~거든요)는 **해석·배경 설명·시청자가 수긍할 내용**에 쓴다. 장식이 아니라 숨 쉬는 자리다
- 질문 문장은 "~일까요?" / "~했을까요?" / "~겠습니까?" 형태
- "~세요 / ~십시오"는 시청자에게 직접 말을 걸 때만 (훅의 환기, 엔딩의 댓글 유도)
- **합쇼체가 여섯 문장 이상 연속되지 않게 한다.** 뉴스 낭독이 되면 끝까지 듣지 않는다
- 어체가 무거워져도 내용까지 딱딱해지지는 않는다. 숫자·사실 밀도는 그대로 가고, 반말·유행어는 쓰지 않는다
- 어미별 상세 규칙과 예시는 `prompts/collapse-style.md` 1절
- **고정 아웃트로 4줄**(매 영상 동일)은 `prompts/collapse-structure.md` 13절에 있다. 문구를 바꾸려면 그 파일을 고친다
- 한 문장은 짧게. 소리 내어 읽었을 때 한 호흡에 끝나야 한다
- 감탄사·선정적 표현 금지. 감정은 숫자와 사건으로 전달한다

## 사실 확인
- 기본 **ON**: WebSearch/WebFetch로 핵심 숫자(매출·점유율·매장 수·주가·직원 수·연도)를 확인한다
- 확인 못 한 숫자는 대본에 단정형으로 쓰지 않는다 → "약", "~로 알려져 있어요", 또는 제외
- 검색 도구를 쓸 수 없는 환경이면 배너에 `팩트체크 OFF`로 표시하고, 완성본 마지막에 [확인 필요] 목록을 남긴다
