# TV홈쇼핑 — 제작 브리프

- 주제: 한국 TV홈쇼핑 산업의 몰락
- 목표 길이: 23분 (사용자 지정 "1만자 내외")
- 목표 글자수: 10,000자 (허용 9,200 ~ 10,800자, ±8%)
- 분당 글자수: 430자 (config/profile.md)
- 주 시청자: 30~70대 한국인, 경제·기업 관심층 + 일반 대중
- 톤: 차분한 다큐
- 팩트체크: ON (WebSearch)
- 사용자 제공 자료: 공식통계 2건 + 언론 5건 + 학술논문 9편 (우선 사용 7편)
- 사용자 지정 흐름: 전성기 회상 → 성공 해부 → 첫 균열 → 구조적 문제 → 새 경쟁자 → 생존 시도 → 남은 문제 → 진짜 원인 → 현재·결론
- 사용자 지정 3단계 전환:
  1. "스마트폰 때문인가?" → 송출수수료로 시선 전환
  2. 라이브커머스·유튜브가 홈쇼핑의 방식을 가져갔다는 아이러니
  3. "그런데 홈쇼핑 회사가 망한 건 아니다" → 기업의 몰락이 아니라 TV라는 유통방식의 쇠퇴
