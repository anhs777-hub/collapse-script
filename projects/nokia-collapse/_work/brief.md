# 노키아 — 브리프

| 항목 | 값 | 출처 |
|------|-----|------|
| 주제 | 노키아(Nokia)의 몰락과 재부상 | 사용자 지정 |
| 목표 길이 | 약 23분 | 사용자 "1만자 내외" → 10,000 ÷ 430 |
| 목표 글자수 | **10,000자** (허용 9,200~10,800자, ±8%) | profile.md 분당 430자 |
| 주 시청자 | 30~70대 한국인, 경제·기업 관심층 + 일반 대중 | profile.md 기본값 |
| 톤 | 차분한 다큐 | profile.md 기본값 |
| 팩트체크 | **ON** (WebSearch 사용) | — |

## 사용자 추가 요구사항 (최우선)
1. "아이폰 때문에 망했다"로 끝내지 말 것 → 시장 지배 → 내부 조직 문제 → 플랫폼 전환 실패 → 윈도우 선택 → 휴대폰 사업 매각의 입체 구성
2. **몰락으로 끝내지 말고, 최근 다시 살아나고 있다는 내용을 반드시 넣을 것** → TODAY 섹션 비중 확대(6% → 8%), ENDING도 부활을 해석에 포함
3. 사용자가 제공한 1차 출처(SEC 공시·MS 공식 발표·논문 4편)를 우선 사용

## 참고 레퍼런스
- 유튜브 레퍼런스(https://www.youtube.com/watch?v=eR9Fn151880): 이 환경의 네트워크 정책상 youtube.com 접근 차단 → 영상 내용 직접 확인 불가.
  대신 `config/profile.md`의 레퍼런스 9편 분석 결과(20~22분이 조회수 상위)와 `prompts/` 구조 규칙을 그대로 적용.
