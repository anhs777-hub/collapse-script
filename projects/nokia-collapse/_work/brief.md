## 사용자 특별 지시
1. "아이폰 때문에 망했다"로 끝내지 말 것. 시장 지배 → 내부 조직 문제 → 플랫폼 전환 실패 → Windows 선택 → 휴대폰 사업 매각까지 입체적으로.
2. **최근 다시 살아나고 있다는 내용을 반드시 넣을 것** → TODAY 섹션 분량을 늘린다.
3. 사용자 제공 1차 자료(SEC 공시·MS 공식 발표·논문 4편)를 우선 사용.
