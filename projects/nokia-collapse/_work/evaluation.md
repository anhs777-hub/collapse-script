# 노키아 — 적합도 평가

| 기준 | 점수 | 근거 한 줄 |
|------|------|-----------|
| 인지도 | 10/10 | 한국 30~70대 대부분이 "노키아"라는 이름과 벽돌폰 이미지를 안다 |
| 전성기와 몰락의 낙차 | 10/10 | 세계 휴대폰 1위 14년 · 점유율 38% → 휴대폰 사업 통째로 매각 |
| 몰락 원인의 흥미도 | 10/10 | 기술이 없어서가 아니라 조직 내부의 두려움·정보 왜곡 때문이었다는 연구 결론 + "그때는 윈도우가 합리적으로 보였다"는 반전 |
| 향수 또는 대중적 경험 | 6/10 | 세계 1위였지만 한국에서는 거의 안 팔렸다. 다만 이 역설 자체가 한국 시청자에게 훅이 된다 |
| 자료화면 확보 가능성 | 9/10 | 전성기 광고·발표회·엘롭 기자회견·주가 차트·MS 인수 발표 영상 모두 풍부 |
| 현재 검색 관심도 | 10/10 | 2025년 엔비디아 10억 달러 투자, 2026년 주가 급등으로 국내 언론 재조명 중 |
| 댓글 토론 가능성 | 9/10 | "안드로이드를 택했어야 했나"는 지금도 찬반이 갈리는 주제 |
| **총점** | **64/70** | |

## 판정
- 55~70 구간 → **강력 추천**
- 가장 낮은 항목: 향수/대중적 경험(6점) → 보완 방향: 한국에서 노키아를 못 산 이유(1990년대 텔슨전자 하청·AS 부실, 2009년 4월 WIPI 의무화 해제 후 6210s 재진출 실패)를 THE PEAK에 한 문단 넣어 "세계 1위인데 우리만 몰랐던 회사"라는 한국 전용 앵글로 전환한다.
- 추천 톤: **차분한 다큐** — 조직 내부 심리와 플랫폼 전환이라는 구조적 이야기라서, 감정을 올리기보다 숫자와 연구 결과를 차분히 쌓는 편이 설득력이 높다.
