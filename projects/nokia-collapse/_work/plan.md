# 노키아 — 스토리 설계

## 핵심 미스터리
세계 휴대폰의 40%를 쥐고, 스마트폰도 남들보다 먼저 만들어 팔던 회사가, 왜 6년 만에 휴대폰 사업을 통째로 팔아야 했을까?

## 성공 공식 → 몰락 연결점
- 성공 공식: 모토로라가 놓친 디지털 전환을 먼저 잡고, **좋은 기계를 여러 종류로, 빨리, 전 세계에 깔았다.**
- 몰락으로 되돌아온 방식: 기종을 늘릴수록 심비안은 기종마다 갈라졌다. 기계를 잘 만드는 능력이 소프트웨어 부채로 바뀌었고, 경쟁의 단위가 '기계'에서 '플랫폼'으로 넘어간 순간 이 공식이 족쇄가 됐다.

## 몰락 원인 3개 (인과 사슬)
1. **내부 구조**: 다품종 하드웨어 전략 → 심비안 파편화 → 신제품 개발이 갈수록 느려짐
2. **경영 오판**: 2011년 플랫폼 선택. 선택지는 MeeGo / Android / Windows Phone.
   - A(안드로이드)를 고르면 물량은 빠르지만, 노키아가 운영체제를 가진 플랫폼 기업에서 **하드웨어 제조사로 내려앉을 위험**
   - B(윈도우폰)를 고르면 MS의 자금·검색·오피스와 함께 '제3의 생태계'의 주인이 될 수 있다고 봤다
   - B를 고른 이유: 차별화 유지 + MS의 수십억 달러 지원 + 당시 경영진의 산업 가정 붕괴 상태에서의 판단 (2024 논문)
3. **외부 사건**: 아이폰·안드로이드가 경쟁의 규칙을 '좋은 기계 싸움'에서 '앱·개발자·생태계 싸움'으로 바꿈

사슬: 다품종 전략 → 심비안 복잡도 폭증 → 개발 지연 → (조직 내 두려움으로) 나쁜 소식이 위로 안 올라감 → 최고경영진 현실 인식 지연 → 뒤늦게, 짧은 기간에 플랫폼 결정 → 윈도우폰 전면 전환 발표로 심비안 즉사 → 새 폰이 나오기까지 18개월 공백 → 매출·현금·신용등급 붕괴 → 2013년 휴대폰 사업 매각

**숨은 축(2016 논문)**: 두려움 → 정보 왜곡 → 인식 지연. 이 축이 원인 1과 2를 잇는다. THE REAL REASON에서 회수.

## 표면적 원인 vs 진짜 원인
- 사람들이 말하는 원인: "2007년 아이폰이 나와서 망했다"
- 진짜 원인: 노키아는 스마트폰을 못 만든 회사가 아니었다. 경쟁의 단위가 기기에서 플랫폼으로 바뀌었는데, 그 변화를 **회사 안에서 아무도 위로 정직하게 전달하지 못했다.** 아이폰은 원인이 아니라 이미 있던 문제를 터뜨린 계기였다.

## FALSE SAFETY / POINT OF NO RETURN
- FALSE SAFETY: 6번 섹션 — 2010년까지도 판매 대수는 계속 늘었고, 메이고라는 자체 카드도 있었다. "여기까지는 아직 되돌릴 수 있는 위기였어요."
- POINT OF NO RETURN: 8번 섹션 — **2011년 2월 11일**, 윈도우폰 전면 전환 발표. 그날 심비안은 살아 있지만 아무도 사지 않는 제품이 됐다.

## 엔딩 한 문장
노키아를 무너뜨린 건 아이폰이 아니라, 경쟁의 규칙이 바뀌었다는 사실을 회사 안 누구도 위로 올려 보내지 못한 몇 년이었어요. 그리고 지금 다시 오르고 있는 노키아는, 그 규칙을 이길 수 있는 다른 싸움터로 옮겨간 회사예요.
