# 리서치 규칙 (RESEARCH 단계) → `_work/research.md`

목표: 대본에 들어갈 **숫자와 사건을 출처와 함께** 모은다. 스토리는 아직 만들지 않는다.

## 검색 원칙
- 팩트체크 ON: WebSearch로 한국어·영어 병행 검색. 핵심 숫자는 가능하면 2개 출처로 교차 확인
- 우선 출처: 공시·연차보고서 · 주요 언론(로이터·블룸버그·조선·한경·매경 등). 위키피디아는 시작점으로만 쓰고 숫자는 원출처로
- 서로 다른 숫자가 나오면 더 권위 있는 출처를 택하고 `(출처 간 차이 있음)` 표시
- 확인 못 한 항목은 `[미확인]` 표시. 지어내지 않는다
- **논문은 학술지명·권·호·연도·쪽수까지 적는다.** 대본에서 `논문`이라고 부르려면 이 정보가 있어야 하고, 검색으로 색인(ScienceDirect·SAGE·Wiley 등)을 확인해야 한다. 확인 못 하면 `분석`으로 낮춰 쓰거나 뺀다 (`collapse-style.md` 1절)
- 검색 횟수 가이드: 20분 대본 기준 14~22회. 전성기 5, 균열·오판 6, 결정타·붕괴 5, 현재 3

## 수집 항목표

| 항목 | 값 | 연도 | 비교 축 | 출처 |

| 매출 | | | 현재 가치 환산 / 경쟁사 대비 | |
| 시장점유율 | | | 순위 / 2위와의 격차 | |
| 매장 수 / 사용자 수 | | | 인구 대비 | |

### B. 성공 공식
- 이 회사만 했던 것 (한 줄) + 근거 사건 2~3개
- 훗날 몰락과 연결될 요소 후보

### C. 균열과 오판 (FIRST CRACK · MISTAKE #1 · #2용)
- 첫 이상징후: 연도 + 숫자 (매출 성장률 둔화, 부채비율, 이익률 등)
- 내부 구조 문제: 무엇이 언제부터 (부채·과잉투자·조직·품질·기술)
- 결정적 선택: 연도 · 선택한 것 · 대안은 무엇이었나 · 당시 경영진이 밝힌 이유 (인터뷰·발표 인용 가능하면)
- 같은 시기 경쟁사의 다른 선택

### D. 결정타와 붕괴 (POINT OF NO RETURN · COLLAPSE용)
- 결정적 사건: 연도 · 사건 · 직후 숫자 변화
- **몰락 시계열 (필수)**: 핵심 지표 1~3개를 연도별로 4단계 이상
  ```
  점유율: 2007 40% → 2009 25% → 2011 12% → 2013 3%
  주가: 고점 100 → 67 → 31 → 5
  ```
- 파산·매각·상장폐지·해체 등 최종 결과 + 날짜

### E. 후일담 (AFTERMATH용)
- 창업자·CEO의 이후 (인터뷰 발언·재창업·소송)
- 직원 수 변화 · 공장·매장 폐쇄와 지역 영향
- 브랜드 매각처 · 매각가
- 경쟁사 생존 여부

### F. 현재 (TODAY용)
- 존재 여부 · 현재 소유주 · 현재 매출/매장 수 · 남은 사업 · 재도전·부활 시도

### G. 표면적 원인 vs 진짜 원인 후보
- 대중이 흔히 말하는 원인 (검색 상위 담론)
- 분석가·연구가 지목하는 구조적 원인

### H. 자료화면 후보
- 전성기 광고·CF · 매장 사진 · 창업자 인터뷰 · 뉴스 보도 · 주가 차트 · 폐점 사진 등 (검색으로 존재 여부 확인)
- 한국 방영 광고·국내 뉴스 화면이 있으면 우선 확보. 40~70대 시청자의 기억을 직접 건드린다
