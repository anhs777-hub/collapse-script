# 문체 규칙 · 금지 표현 · TTS 규칙 (DRAFT · REVIEW 단계)

## 1. 문체 규칙

시청자는 **30~70대**다. 40~70대는 그 브랜드의 전성기를 직접 겪은 세대이고, 30~40대는 이야기로만 아는 세대다. 두 쪽 모두 이해하게 쓴다.

### 채널의 말투 — 길게 깔고, 짧게 꽂는다

이 채널의 소리는 한 줄로 정리된다. **차분하게 자료를 보여주다가, 중요한 순간에 짧고 쉬운 말로 꽂는다.**

아래 여섯 문장이 기준점이다. 새 대본을 쓸 때 **이 문장들과 같은 소리가 나는지**로 판단한다.

```
근데 이상한 게 하나 있어요.
그럴 만도 했습니다.
그런데 접었어요.
사람들이 무서워서 말을 못 했던 겁니다.
팔 물건이 없는 9개월이었습니다.
없는 게 별로 없었습니다. 그런데 딱 하나를 놓쳤죠.
```

공통점은 다섯 가지다.

- **15자 안팎.** 소리 내어 읽으면 한 호흡에 끝난다
- **혼자 문단을 차지한다.** 앞뒤가 빈 줄이라 화면에서도 자막 한 장이 된다
- **어려운 단어가 하나도 없다.** 한자어·업계 용어·수식어가 없다
- **새 정보를 주지 않는다.** 앞에서 길게 깔아둔 것을 받아 요약하거나, 방향을 튼다
- **앞 문단이 길어야 성립한다.** 긴 설명 뒤에 와야 대비로 꽂힌다

#### 어디에 놓는가

| 자리 | 하는 일 | 예 |
|------|---------|-----|
| **반전 신호** | 시청자가 아는 것을 흔들기 직전 | 근데 이상한 게 하나 있어요 |
| **판단 받기** | 경영진의 선택을 설명한 뒤 조롱하지 않고 닫을 때 | 그럴 만도 했습니다 |
| **사건 압축** | 여러 문장으로 설명한 일을 동사 하나로 | 그런데 접었어요 |
| **결론 번역** | 논문·구조 설명을 일상어 한 줄로 | 사람들이 무서워서 말을 못 했던 겁니다 |
| **상태 명명** | 기간이나 숫자에 이름을 붙일 때 | 팔 물건이 없는 9개월이었습니다 |
| **나열 뒤 반전** | 길게 나열하고 짧게 뒤집을 때 | 없는 게 별로 없었습니다. 그런데 딱 하나를 놓쳤죠 |

- **섹션마다 1개 이상**, 대본 전체에서 **10~15개**. 13개 섹션이면 평균 한 섹션에 하나꼴이다
- **연달아 쓰지 않는다.** 꽂는 문장이 두 개 붙으면 둘 다 죽는다. 사이에 최소 한 문단은 자료가 들어간다
- **억지로 만들지 않는다.** 앞에 깔아둔 게 없는데 짧은 문장만 던지면 허세가 된다. **긴 문단이 먼저다**
- 상태 명명형은 **제목·썸네일·챕터 자막으로 그대로 가져다 쓴다** ("팔 물건이 없는 9개월")
- **HOOK은 예외.** 통념 한 줄 뒤에 곧바로 꽂는다 ("아이폰이 나오자 노키아가 무너졌다. 보통 그렇게 알고 계실 겁니다." → "근데 이상한 게 하나 있어요."). 훅에서는 긴 문단을 기다리지 않는다

#### 세지 않는 것

짧은 단독 문단이라고 다 꽂는 문장은 아니다. 아래 넷은 각자 다른 장치이고, **10~15개 집계에서 제외한다.**

| 제외 | 하는 일 | 예 |
|------|---------|-----|
| **전환 질문** | 다음 단락으로 넘기는 다리 | 그럼 왜 접었을까요 / 스마트폰 점유율을 따라가 볼까요 |
| **인용** | 메모·보고·발언을 그대로 옮긴 것 | 우리는 불타는 플랫폼 위에 서 있다 / 개발 일정을 못 맞춥니다 |
| **목록 도입** | 뒤에 나올 항목의 개수 예고 | 노키아가 쥔 무기는 셋이었습니다 |
| **장면 전환** | 화면이 바뀐다는 신호 | 한국에서도 마지막 장면이 있었습니다 |

넷 다 필요한 장치다. 다만 **꽂는 문장은 앞의 내용을 받아서 뒤집거나 요약하는 것**이고, 위 넷은 뒤에 올 것을 여는 문장이다. 방향이 반대다.

#### 이 말투가 아닌 것

```
✗ 충격적인 반전이 기다리고 있었습니다.        ← 내용 없는 예고
✗ 과연 무슨 일이 벌어졌을까요?                ← 앞에 받을 게 없는 질문
✗ 이것이야말로 노키아의 결정적 실책이었습니다. ← 수식어와 한자어
✗ 그런데 접었어요. 놀라운 일이었죠.           ← 꽂는 문장을 두 개 붙임
✓ 그런데 접었어요.
```

### 어미 — 합쇼체 60 : 해요체 40

차분하게 사실을 짚어주는 다큐 내레이션이 기본이다. 다만 끝까지 합쇼체로만 가면 뉴스 낭독이 되고, 뉴스 낭독은 20분을 버티지 못한다. **열 문장 중 여섯은 합쇼체, 넷은 해요체**로 간다.

| | 어미 | 쓰는 자리 | 목표 |
|---|------|----------|------|
| 기본 | `~습니다 / ~입니다` | 사실·숫자·사건의 서술. 시간이 흐르는 문장 | 약 60% |
| 공감 | `~죠 / ~거든요` | 시청자가 이미 알거나 수긍할 내용, 배경 설명 | 해요체 몫의 절반 |
| 해석 | `~어요 / ~아요 / ~예요 / ~이에요` | 사실이 아니라 **해석**을 얹는 문장, 장면 전환 | 해요체 몫의 절반 |
| 질문 | `~일까요? / ~했을까요? / ~겠습니까?` | 미스터리 제시, 섹션 전환 | 섹션당 1~2회 |
| 말 걸기 | `~세요 / ~십시오` | 시청자에게 직접 말할 때만. HOOK의 환기, ENDING의 댓글 유도 | 대본 전체에서 2~3회 |

- **비율은 문장 끝 기준이고, 허용 폭은 각 ±10%p다** (합쇼체 50~70%, 해요체 30~50%).
- **합쇼체가 여섯 문장 이상 연속되지 않게 한다.** 서너 문장 사실을 쌓았으면 한 문장은 해요체로 풀어준다. 그 한 문장이 시청자가 숨 쉬는 자리다.
- **어느 문장을 해요체로 둘지는 내용이 정한다.** 사실·숫자·사건은 합쇼체, 그것을 해석하거나 시청자가 이미 아는 것을 확인하는 문장은 해요체. 어미를 섞으려고 아무 문장이나 바꾸면 톤이 흔들린다.
  ```
  2008년에 51조 원이던 매출이 2012년엔 30조 원으로 줄어듭니다.   ← 사실
  4년 만에 40%가 사라진 겁니다.                                   ← 사실
  숫자만 보면 시장이 통째로 뒤집힌 것처럼 보이죠.                 ← 해석 (해요체)
  하지만 그 4년 동안 회사가 한 일은 거의 없었습니다.              ← 사실
  ```
- 같은 어미가 세 문장 연속 반복되면 바꾼다. `~습니다`가 이어지면 `~됩니다`·`~집니다`·`~입니다`로 형태를 바꾸거나 해요체 한 문장을 넣는다.
- **맞춤법**: 받침 없는 말 뒤는 `예요`(노키아예요), 받침 있는 말 뒤는 `이에요`(사장이에요). `에요`는 "아니에요"에만 쓴다.
- **어체가 무거워져도 내용까지 딱딱해지지는 않는다.** 숫자·출처·사실 밀도는 그대로 간다. 반말·유행어·이모티콘 어투는 쓰지 않는다.

### 문장 만들기

- **한 문장을 짧게.** 소리 내어 읽었을 때 한 호흡에 끝나야 한다. 절이 두 개 이상 겹치면 쪼갠다.
- **구어체 나레이션.** 문어체 보고서가 아니라, 사람이 앞에서 이야기해주는 말투.
- **어려운 용어는 처음 나올 때 한 번 풀어서 설명한다.** 경제·금융 용어와 업계 외래어 모두 해당한다. "영업이익, 그러니까 물건을 팔아 실제로 남긴 돈이…" 두 번째부터는 그냥 쓴다. 매번 풀어쓰면 설명이 늘어져 지루해진다.
- **숫자를 적극 활용한다.** 추상어("경영이 어려워졌어요") 대신 구체적 숫자와 사건("영업이익이 3년 만에 절반으로 줄었어요").
- **추상적 표현보다 구체적인 사건.** "경쟁이 치열해졌어요" ✗ → "1년 사이 경쟁사 세 곳이 같은 가격대 제품을 내놨어요" ✓
- **감탄사·선정적 표현 금지.** 감정은 숫자와 사건이 만든다.
- **확인되지 않은 사실을 단정하지 않는다.** research.md에 `[미확인]`인 숫자는 "약", "~로 알려져 있어요"로 쓰거나 뺀다.
- **경영진을 결과론으로 조롱하지 않는다.** "바보 같은 선택" ✗ → 당시 그 선택이 왜 나왔는지 설명한다.
- **첫 등장은 반드시 이름으로.** 회사·인물·제품을 "이 회사", "그 사람"으로 먼저 부르지 않는다. 음성은 되돌릴 수 없다. HOOK에서 미스터리를 위해 지시어로 시작하더라도 늦어도 40초 안에 이름을 밝힌다.
- **주어를 문장 앞에.** 수식어·조건절로 문장을 시작하지 않는다.
- **숫자 변화는 전후 값으로.** "20%p 하락" ✗ → "40%였던 점유율이 20%로" ✓
- **연도에는 앵커를 붙인다.** 연도만 던지면 그 시절을 겪지 않은 시청자에게는 아무 의미가 없다. 한국인이 기억하는 사건을 옆에 붙인다. "1998년" ✗ → "IMF 외환위기 이듬해인 1998년" ✓. 한 섹션에 한두 번이면 충분하다.
- **금액은 체감 단위로 환산한다.** 억 달러·조 원은 크기가 실감되지 않는다. "당시 서울 아파트 몇 채 값", "그때 대졸 초봉의 몇 배", "국민 한 사람당 얼마" 같은 환산을 먼저 주고 원래 숫자를 뒤에 붙인다.
- **시각을 염두에 두고 쓴다.** 이 문장이 화면에서 그래프·사진·자막 중 무엇이 될지 생각한다. 단, 연출 지시는 본문에 쓰지 않는다.

### 비유는 아껴 쓴다 — 대본 전체에서 3개까지

비유는 한 편에 서너 개 있을 때 기억에 남고, 열 개가 넘어가면 문장마다 힘을 주는 글이 된다. **대본 전체에서 3개를 넘기지 않는다.**

쓰려면 아래 셋 중 하나에 해당해야 한다. 어디에도 걸리지 않으면 평서문으로 쓴다.

| 허용 | 조건 | 예 |
|------|------|-----|
| **출처가 있는 비유** | 실제 발언·문서의 인용이거나 업계에서 굳어진 용어. 대본 안에서 출처를 밝힌다 | "불타는 플랫폼 위에 서 있다" (엘롭 메모 인용) / "오스본 효과" (용어 + 유래 설명) |
| **바로 회수되는 비유** | 앞이나 뒤 문장이 그 비유를 사실로 풀어준다 | 본사를 팔고 임차료를 냈다는 설명 뒤에 → "자기 건물에서 세입자가 된 겁니다" |
| **숫자 환산** | 큰 숫자를 몸으로 아는 단위로 바꾸는 것. 이건 비유가 아니라 번역이다 | "국민 한 사람당 43만 원" / "한국 인구의 아홉 배" |

**금지 — 설정 없이 던지는 비유.** 앞뒤 어디에도 근거가 없는데 분위기로 쓰는 것. 듣는 사람이 "갑자기 무슨 소리지?"에서 멈추면 그 문장은 실패다.
> ✗ 그런데 이 **결혼**도 오래 못 갔습니다 (두 회사를 부부로 부른 적이 없다)
> ✓ 그런데 이 인수도 오래가지 못했습니다

**금지 — 같은 계열 비유의 반복.** 죽음(사망 선고·죽였다·숨통), 전쟁(전선·백기·항복), 신체(발목·상처·심장)는 계열당 **한 번까지**. 세 번 나오면 그 계열이 대본의 말투가 되어버린다.

**판단이 서지 않으면 빼는 쪽.** 비유를 뺀 평서문은 밋밋할 뿐이지만, 어긋난 비유는 화자를 의심하게 만든다.

### 서술어가 주어와 맞는지 소리 내어 본다

멋있어 보이는 조합이 문법적으로 성립하지 않는 경우가 많다. **추상 명사에 사람의 행위 동사를 붙이지 않는다.**

```
✗ 아이폰이 나오기 직전 수준을, 이제야 다시 만났다는 겁니다.   ← 수준은 만나는 대상이 아니다
✓ 아이폰이 나오기 직전 주가를, 이제야 회복한 겁니다.
```

한 문장을 쓰고 **주어와 서술어만 남겨 읽어본다.** "수준을 만났다", "매출이 걸어갔다", "점유율이 숨을 쉬었다"처럼 어색하면 동사를 바꾼다.

### 연구·논문은 결과를 먼저, 출처를 뒤에

같은 사실이라도 순서에 따라 논문 요약처럼 들리기도 하고 이야기처럼 들리기도 한다. **발견한 내용을 먼저 말하고, 출처는 그 뒤에 한 줄로 붙인다.**

```
✗ 2016년 경영학 학술지 어드미니스트레이티브 사이언스 쿼털리에 실린 논문입니다.
  제목은 혁신 과정에서의 분산된 주의와 공유된 감정. 이 연구에 따르면 노키아 내부에는…

✓ 사람들이 무서워서 말을 못 했던 겁니다.
  윗사람들은 애플과 구글이 무서웠고, 중간관리자들은 자기 상사가 무서웠어요.
  …
  이건 추측이 아닙니다. 2016년에 티모 부오리와 퀴 후이 두 연구자가
  당시 노키아 경영진과 중간관리자를 직접 인터뷰해서 밝혀낸 내용이에요.
```

- 나레이션에는 **연도 + 연구자 이름**까지만 넣는다. **학술지명과 논문 제목은 화면 자막으로 보낸다** (`_work/기획서.md` 11번 편집 노트에 자막 문구를 적는다)
- 한 대본에서 이 구조를 **세 번 이상 반복하지 않는다.** 네 번째부터는 "~라는 분석도 있어요" 정도로 가볍게 처리하거나 뺀다
- 논문을 빼라는 뜻이 아니다. 이 채널의 차별점이 학술 근거이므로 **내용은 살리고 등장 방식만 바꾼다**

## 2. 반드시 피해야 할 표현 (검수 시 grep)

AI 대본 특유의 상투적 표현. 발견 즉시 **구체적 사실·상황**으로 교체한다.

| 금지 | 대신 |
|------|------|
| 그의 열정은 대단했습니다 | 그가 실제로 한 행동 (하루 매장 3곳 방문 등) |
| 성공가도를 달리게 됩니다 | 구체적 숫자 (3년 만에 매출 10배) |
| 역사의 뒤안길로 사라집니다 | 실제 결말 (2013년 사업부 매각, 브랜드 소멸) |
| 운명의 장난이 시작됩니다 | 실제 사건 |
| 이 사건은 큰 충격을 줬습니다 | 충격의 실체 (주가 하루 30% 하락) |
| 우리에게 중요한 교훈을 줍니다 | 해석 한 문장 (ENDING 규칙) |
| 무능했습니다 / 바보 같은 | 당시 선택의 논리 |
| 엄청난 / 어마어마한 / 대단한 | 비교 가능한 숫자 |
| 안타깝게도 / 불행히도 | 삭제 |

표는 합쇼체로 적었지만 **어체와 무관하게 잡는다** ("사라집니다"·"사라져요" 둘 다 금지).
그 밖에도 "~하게 됩니다"의 연속 반복, "그리고 다음 사건이 벌어집니다" 같은 밋밋한 전환은 리텐션 브리지로 교체한다.

### 2-1. 손버릇 비유 — 발견 즉시 평서문으로

위 1절 「비유는 아껴 쓴다」의 3개 한도를 지켜도, 아래 표현들은 **한도에 넣지 말고 그냥 뺀다.** 어디에나 붙어서 특정 소재의 것으로 기억되지 않는 표현들이다.

| 금지 | 대신 |
|------|------|
| 늙은 거인 / 공룡 / 골리앗 | 처음부터 1등이던 회사 / 변화가 느린 1위 |
| 발목을 잡습니다 | 가장 큰 문제가 됩니다 |
| 등을 돌립니다 | 같은 판정을 내립니다 / 거래를 끊습니다 |
| 사망 선고를 내렸다 / 숨통을 끊었다 | 먼저 접겠다고 발표했다 / 단종을 공지했다 |
| 딴소리를 합니다 | 다르게 나옵니다 |
| 청구서로 돌아왔다 / 부메랑이 됐다 | 비용이 됐다 / 그 자리에서 문제가 됐다 |
| 문이 열립니다 / 창이 열립니다 | 순위가 흔들립니다 / 기회가 생깁니다 |
| 시장을 먹고 있었다 | 시장의 절반이 그 회사였다 |
| 회복 가능한 상처 | 돌이킬 수 있는 단계 |
| 각본을 반대편에서 읽었다 | 20년 전 A가 B에게 했던 일을 이번엔 A가 당했다 |
| 돌아가는 세상을 샀다 | 그 안에서 뭘 할 수 있는지를 보고 골랐다 |
| 말이 예뻐집니다 | 표현이 부드러워집니다 |
| 피가 마르는 / 벼랑 끝 / 마지막 카드 | 실제 상황과 숫자 |

**환산은 정확해야 한다.** 숫자를 체감 단위로 바꿀 때 나눗셈을 실제로 해본다.
> ✗ 점유율 50%에서 3.5%로 → "서른 명 중 한 명만 남은 셈" (50÷3.5 = 14.3이다)
> ✓ "5년 만에 점유율이 14분의 1로 줄어든 겁니다"

## 3. 좋은 문장 예시

✗와 ✓의 차이는 **어체가 아니라 추상어냐 숫자냐**다. 합쇼체로 써도 추상어면 그대로 실패한다.

```
✗ 노키아는 2007년 세계 휴대전화 시장에서 압도적인 점유율을 기록하며 성공가도를 달리고 있었습니다.
✓ 2007년, 전 세계에서 팔린 휴대전화 10대 중 4대가 노키아였습니다.

✗ 경영진은 무능하게도 스마트폰 시장의 변화를 무시했습니다.
✓ 경영진 판단은 이랬습니다. 터치스크린 폰은 비싸다, 배터리도 하루를 못 버틴다, 우리 고객은 그런 걸 원하지 않는다. 당시 판매 데이터만 놓고 보면 틀린 말도 아니었죠.

✗ 매출이 급격히 감소했습니다.
✓ 2008년에 51조 원이던 매출이 2012년엔 30조 원으로 줄어듭니다. 4년 만에 40%가 사라진 겁니다.

✗ 1997년, 회사는 3조 원의 부채를 안고 있었습니다.
✓ 외환위기가 터진 1997년, 회사가 진 빚은 3조 원이었습니다. 그해 국민 한 사람이 6만 원씩 갚아야 하는 돈이었죠.

✗ 레버리지를 활용한 차입 매수로 인수에 성공합니다.
✓ 인수 대금 대부분을 빚으로 채웠습니다. 사들인 회사가 벌어들일 돈으로 그 빚을 갚겠다는 계산이었죠.
```

— 60 : 40 비율을 놓치면 이렇게 됩니다 —

```
△ 매출이 급격히 감소했습니다. 점유율도 떨어졌습니다. 직원도 줄었습니다. 공장도 닫았습니다. 대리점도 사라졌습니다. 남은 건 브랜드뿐이었습니다.
  (합쇼체 6연속 — 뉴스 낭독이 된다. 세 번째나 네 번째를 "직원도 줄었고요"·"공장까지 닫았죠"로 푼다)

△ 2008년 51조 원이던 매출이 2012년엔 30조 원으로 줄었어요. 점유율도 같이 빠졌어요. 직원도 줄었어요.
  (해요체 3연속 + 같은 어미 반복 — 사실과 숫자를 나열하는 자리는 합쇼체가 기본이다)

△ 매출이 급격히 감소했어요.
  (어미만 바꾼 것 — 추상어는 어떤 어미를 붙여도 설득되지 않는다)
```

## 4. TTS 규칙 (output/01_대본.txt 생성 시)

`output/01_대본.txt`는 음성 합성기가 그대로 읽는 파일이다. **내용은 바꾸지 않고 형식만** 정리한다.

1. 문장 끝 온점 뒤 반드시 띄어쓰기
2. 따옴표 사용 금지 → 제거. 인용은 "~라고 말했어요" 형태로 풀어쓴다
3. 문단 구분은 빈 줄로. 섹션 제목(`## 1. HOOK`)은 제거하고 빈 줄만 남긴다
4. 특수문자(※ ★ → 등)·이모지 금지. `%`는 허용. 화살표 시계열은 "40%에서 25%로" 형태로 풀어쓴다
5. URL·이메일 삽입 금지
6. 단어 뒤 괄호 금지 → 괄호와 내용을 함께 제거 (`노키아(Nokia)` → `노키아`). 필요한 영문명은 본문에서 풀어 쓴다
7. 나레이션이 아닌 텍스트(제목·장면번호·연출지시·[미확인] 태그) 제거
8. 숫자·단위는 소리 나는 대로 읽어도 어색하지 않게 (`3.5조` → `3조 5천억 원`, `2007년` 유지, `40%` 유지)
