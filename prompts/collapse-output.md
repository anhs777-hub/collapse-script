- **업로드할 때 필요한 것만** 넣는다. 제목 후보·썸네일 문구는 02에만 쓰고 여기 넣지 않는다.

- 제목은 02의 추천 1번을 **그대로** 쓴다. 여기서 새로 짓지 않는다.

### 설명글 서식 (필수)

유튜브 설명글은 마크다운이 렌더링되지 않고 **줄바꿈만 그대로 보인다.**

- 섹션과 섹션 사이는 **빈 줄 하나**로 띄운다
- 섹션 안에서는 **줄바꿈만** 한다 (다루는 내용·타임스탬프는 한 줄에 하나씩, 사이에 빈 줄 없음)
- 예외: **주요 출처만** 한 건(제목+URL)마다 빈 줄로 띄운다
- 들여쓰기(줄 앞 공백)를 쓰지 않는다 — 유튜브에서 그대로 노출돼 지저분해진다
- `**굵게**`, `- ` 같은 마크다운 기호를 쓰지 않는다. 불릿이 필요하면 `·` 를 쓴다

### 설명글 구성 — 순서대로

**1. 키워드** (맨 첫 줄) — 핵심 키워드 5개를 `#키워드1, #키워드2, …` 형식으로

**2. 한줄 요약** (1~2문장) — 전성기 숫자와 현재 결과를 충돌시킨다. HOOK의 압축판이되 **몰락 원인의 정답은 쓰지 않는다.**

**3. 📌 이 영상에서 다루는 내용** (3~5줄) — 각 줄 25자 안팎. 파트를 옮긴 목록이 아니라, 훑자마자 "뭘 다루는지" 알게 하는 요약.
```
📌 이 영상에서 다루는 내용
· {한 줄 요약 1}
· {한 줄 요약 2}
· {한 줄 요약 3}
```

**4. ⏱ 타임스탬프** — 13개 섹션을 **7~9개 챕터로 묶어** 만든다.

기본 묶음:

| 챕터 | 묶는 섹션 |
|------|----------|
| 1 | HOOK |
| 2 | THE PEAK + RISE |
| 3 | FIRST CRACK |
| 4 | MISTAKE #1 |
| 5 | FALSE SAFETY + MISTAKE #2 |
| 6 | POINT OF NO RETURN |
| 7 | COLLAPSE |
| 8 | THE REAL REASON |
| 9 | AFTERMATH + TODAY + ENDING |

- 시작 시각 = **앞선 섹션들의 누적 글자수 ÷ 분당 글자수**(`config/profile.md`, 기본 430자) → `MM:SS`로 반올림
- 첫 챕터는 반드시 `00:00` · 챕터 3개 이상 · 각 챕터 10초 이상 (유튜브 챕터 규칙)
- 챕터 제목은 **시청자용 문구로 다듬는다.** `POINT OF NO RETURN` 같은 내부 용어 금지, 스포일러 금지, 짧고 궁금하게
  - ✗ `07:30 MISTAKE #2 — 경영진의 전략적 오판`
  - ✓ `07:30 그때 다른 선택지가 있었다`

- **챕터 제목에는 그 구간 대본에 실제로 나오는 키워드를 넣는다.** 제목만 보고 요약한 문구를 쓰지 않는다.
  - 시청자는 챕터를 눌러 그 지점으로 건너뛴다. 제목에서 본 단어가 나레이션에 없으면 잘못 온 줄 안다
  - 키워드는 **숫자·고유명사·그 구간의 핵심 문장**에서 고른다. 추상어("위기의 시작")는 검색에도 안 걸리고 기억에도 안 남는다
  - 제목을 짓고 나면 **각 키워드를 해당 챕터 글자수 구간 안에서 실제로 찾아본다.** 없으면 제목을 고친다

  ```
  ✗ 04:05 위기의 시작            ← 대본에 없는 말
  ✓ 04:05 아이폰과 안드로이드가 나와도 숫자는 좋았다
           (아이폰 · 안드로이드 · 숫자 — 셋 다 그 구간에 있음)

  ✗ 11:35 돌이킬 수 없는 선택
  ✓ 11:35 불타는 플랫폼, 그리고 팔 물건이 없는 9개월
           (엘롭 메모 인용구 + 그 섹션의 꽂는 문장을 그대로)
  ```

  - **꽂는 문장을 챕터 제목으로 올리는 게 가장 좋다** (`collapse-style.md` 1절). 이미 대본에서 가장 짧고 강한 문장이라 자막으로도 그대로 쓸 수 있다
- 섹션 제목은 반드시 `⏱ 타임스탬프`로 쓴다 — 영상 완성 후 timestamp 스킬("타임스탬프 채워줘")이 전사 실측으로 이 섹션을 통째 교체할 때 찾는 기준이다
- 설명글 본문에는 "예상"이라고 쓰지 않는다 — 추정치 안내는 문서 하단 💡 줄이 담당한다

```
⏱ 타임스탬프
00:00 {챕터1 제목}
{MM:SS} {챕터2 제목}
{MM:SS} {챕터3 제목}
```

**5. 🔗 주요 출처** (필수, **최대 8개**)

- 선정 우선순위: ① 공시·연차보고서·정부·협회 등 1차 자료 ② 제목과 HOOK의 핵심 주장을 지탱하는 보도 ③ 같은 내용이면 매체 하나만
- **뉴스1·뉴시스 기사는 표기 금지** (URL이 news1.kr · newsis.com인 것 포함) — 인용 제한을 요구하는 매체. 그 매체뿐이면 같은 내용의 다른 매체나 1차 자료로 대체한다

## 출력 ⑤ — `{P}/output/04_타임스탬프.txt`

`03_업로드정보.md`의 `⏱ 타임스탬프` 섹션과 **같은 내용**을, 챕터 줄만 남겨 따로 저장한다.
설명글 전체를 붙여넣지 않고 챕터만 따로 쓰고 싶을 때(영상 편집 프로그램의 챕터 입력, 커뮤니티 게시 등) 바로 복사할 수 있게 하는 파일이다.

```
0:00 손님은 빠졌는데 값은 그대로
02:14 얼마나 대단한 회사였나
05:31 숫자에 이상한 변화가 나타납니다
07:10 빚으로 산 확장
...
```

### 형식 규칙

- **챕터 줄만 넣는다.** 제목·머리말·설명·빈 줄 없이 첫 줄부터 바로 시작한다
- 첫 줄은 반드시 `0:00` (유튜브 챕터 규칙)
- 둘째 줄부터는 `MM:SS` — 분을 두 자리로 맞춘다 (`02:14`, `07:10`)
- 시각과 제목 사이는 **공백 한 칸**
- 챕터 제목은 `03_업로드정보.md`의 것과 **한 글자도 다르지 않게** 쓴다
- 챕터 수·제목·묶음 규칙은 03의 `⏱ 타임스탬프` 항목을 그대로 따른다 (13섹션 → 7~9챕터)
- 마지막 줄 뒤에 빈 줄을 남기지 않는다
