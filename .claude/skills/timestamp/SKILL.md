# Timestamp Skill

대본으로 만든 **완성 영상**을 전사해, 유튜브 설명글용 챕터 타임스탬프를 실측으로 만든다.
`03_업로드정보.md`에 처음 들어가는 시각은 대본 글자수로 계산한 **추정치**다 — 영상을 만든 뒤 이 스킬로 실제 시각으로 바꾼다.

## 시작 배너 (필수 — 스킬 발동 시 첫 출력)

```
✅ 타임스탬프 스킬 | 프로젝트: {주제 또는 선택 대기} | 영상: {파일명 또는 대기}
```

루트에 `CLAUDE.md`가 없으면 진행하지 말고 안내한다: "`collapse-script` 폴더 자체를 여신 뒤 다시 시도하세요."

---

## 절차

### 1. 입력 확인

- **영상 파일**: 경로가 없으면 요청한다 — "완성된 영상 파일을 채팅창에 드래그하거나 경로를 알려주세요" (mp4·mov 등 영상, mp3·m4a 등 오디오 모두 가능)
- **프로젝트**: `projects/*/output/03_업로드정보.md`가 있는 것 중에서 고른다. 지정이 없고 여러 개면 **가장 최근에 수정된 것**을 제안하고 확인받는다
- 해당 프로젝트에 `03_업로드정보.md`가 없으면 중단하고 안내한다: "대본 파이프라인을 먼저 끝내야 해요 — '이어서 해줘'라고 말씀해주세요."

### 2. 음성 인식 도구 준비 (첫 1회)

`{PY}` = 시스템 python (macOS: `python3` / Windows: `python`)
`{VENV_PYTHON}` = macOS `.venv/bin/python` · Windows `.venv\Scripts\python.exe`

1. `{VENV_PYTHON} --version` 확인
   - 실패(venv 없음 / 다른 OS에서 만든 `.venv`가 복사됨 / 폴더 이동으로 경로가 깨짐) → 한 줄 알리고 **그 자리에서 복구한다**:
     1. `.venv`가 있으면 삭제: `{PY} -c "import shutil; shutil.rmtree('.venv')"`
     2. 재생성: `{PY} -m venv .venv`
2. 설치·복구는 스크립트 하나가 전부 처리한다 (**timeout 10분**):

   ```bash
   {VENV_PYTHON} scripts/setup_asr.py
   ```

   - 이미 준비돼 있으면 `음성 인식 준비 완료`만 출력하고 즉시 끝난다. 여러 번 실행해도 안전하다
   - 처음이면 `faster-whisper`를 설치한다 (~200MB, 1~3분). 사용자에게 한 줄 알린다: "첫 사용이라 음성 인식 도구를 설치할게요 (2~3분 걸려요)"
   - **Windows에서는 pip 설치가 성공해도 DLL을 못 불러오는 일이 흔하다** (Visual C++ 재배포 패키지 없음). 스크립트가 `msvc-runtime`의 DLL을 복사해 자동 복구한다 — 관리자 권한이 필요 없다
3. 종료 코드가 0이 아니면 중단하고 마지막 출력 줄을 그대로 전한다. 코드 `6`이면 자동 복구까지 실패한 것이다:
   > "음성 인식 도구가 이 컴퓨터에서 실행되지 않아요. Microsoft Visual C++ 재배포 패키지(x64)를 설치하면 해결될 수 있는데, 그전까진 타임스탬프를 손으로 채우셔야 해요."

### 3. 전사

```bash
{VENV_PYTHON} scripts/timestamp.py --video "{영상 경로}"
```

- 출력: `[MM:SS] 문장` 목록. 첫 실행은 모델(~150MB) 자동 다운로드가 추가된다
- 전사는 영상 길이의 절반 정도 걸릴 수 있다 — **timeout을 10분 이상**으로 잡는다. 22분 영상이면 10~15분을 잡는다

### 4. 챕터 시작 시각 결정

`{P}/output/01_대본.txt`(정본 대본)와 `{P}/_work/기획서.md` 5번(전체 스토리 구조)을 읽는다.

**챕터 묶음은 13개 섹션을 7~9개로 묶은 것을 쓴다** (`prompts/collapse-output.md`의 타임스탬프 표와 동일):

| 챕터 | 묶는 섹션 |
|------|----------|
| 1 | HOOK |
| 2 | THE PEAK + RISE |
| 3 | FIRST CRACK |
| 4 | MISTAKE #1 |
| 5 | FALSE SAFETY + MISTAKE #2 |
| 6 | POINT OF NO RETURN |
| 7 | COLLAPSE |
| 8 | THE REAL REASON |
| 9 | AFTERMATH + TODAY + ENDING |

- 각 챕터의 **첫 문장**을 `_work/기획서.md` 8번(본문 대본)에서 찾고, 그 문장을 전사에서 찾아 그 줄의 시각을 챕터 시작 시각으로 삼는다
- 음성 인식 오타가 흔하다("이른바"→"이름바", 브랜드명 오인식). **발음이 비슷하면 같은 문장으로** 판단하고, 애매하면 그 챕터의 다음 문장 두세 개로 교차 확인한다
- 숫자는 특히 자주 틀린다("40%"→"사십 퍼센트"·"사시 퍼센트"). 숫자 문장을 기준점으로 쓰지 않는다
- 유튜브 챕터 규칙: **첫 챕터는 반드시 00:00** · 챕터 3개 이상 · 각 챕터 10초 이상 (너무 짧은 챕터는 이웃과 합친다)
- 챕터 제목은 **기존 `03_업로드정보.md`에 있던 제목을 그대로 쓴다.** 시각만 바꾼다
  - 기존 타임스탬프 섹션이 없을 때만 새로 짓는다 — 내부 용어(`POINT OF NO RETURN`)·스포일러 금지, 짧고 궁금하게

### 5. `03_업로드정보.md` 갱신

`## 설명글`의 `📌 이 영상에서 다루는 내용` 섹션 **아래**에 삽입한다:

```
⏱ 타임스탬프
00:00 {챕터1 제목}
{MM:SS} {챕터2 제목}
...
```

- 이미 `⏱ 타임스탬프` 섹션이 있으면 **통째로 교체한다**
- 다른 섹션(제목·한줄 요약·주요 출처·CTA·태그·고정 댓글)은 건드리지 않는다
- 문서 맨 아래 `💡 위 타임스탬프는 ... 예상 시각입니다` 안내 줄이 있으면 **제거한다** (이미 실측으로 바뀌었으므로)

### 6. 보고

챕터 표(시각 · 제목)를 보여주고 마친다: "`output/03_업로드정보.md` 설명글에 반영했어요 — 그대로 복사해서 쓰시면 됩니다."

전사에서 못 찾은 챕터가 있으면 그 챕터만 **추정치 유지**로 표시하고, 어느 챕터인지 알린다. 지어내지 않는다.
